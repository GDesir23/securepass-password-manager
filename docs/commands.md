# SecurePass Commands

## Main Menu

```text
1. Add Password
2. View Passwords
3. Search Password
4. Delete Password
5. Edit Password
6. Generate Password
7. Exit
```

---

## Features

### Add Password

Stores a website, username, and password.

### View Passwords

Displays all saved password entries.

### Search Password

Searches for a saved password by website.

### Delete Password

Deletes a saved password.

### Edit Password

Updates an existing password entry.

### Generate Password

Creates a secure random 16-character password.

### Exit

Saves all password entries and closes the application.
